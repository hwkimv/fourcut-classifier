# 네컷사진 판별 AI 프로젝트

## 📌 프로젝트 개요

이 프로젝트는 **단층 퍼셉트론(Single Layer Perceptron)** 을 사용하여 사진이 "네컷 사진"인지 "일반 사진"인지 자동으로 분류하는 인공지능 모델입니다.

**네컷 사진**이란? 
- 포토부스에서 찍는 사진으로, 보통 4개의 작은 사진이 격자 형태로 배열된 사진입니다.
- 예: □□ (2×2 격자 구조)
     □□

**프로젝트 목표:**
- 주어진 이미지를 보고 "네컷 사진"인지 "일반 사진"인지 자동으로 판별

---

## 🧠 인공지능 모델 설명

### 1. 단층 퍼셉트론(SLP)이란?

**퍼셉트론**은 인공지능의 가장 기본적인 구성 요소로, 사람의 뇌에 있는 **뉴런(신경세포)** 을 모방한 것입니다.

#### 🔹 뇌의 뉴런과 비교
```
[사람의 뉴런]
입력(자극) → 뉴런(처리) → 출력(반응)

[인공 퍼셉트론]
입력(이미지) → 퍼셉트론(계산) → 출력(네컷/일반)
```

#### 🔹 왜 "단층"인가?
- **단층(Single Layer)**: 입력과 출력 사이에 **한 개의 층**만 있는 가장 간단한 구조
- 복잡한 딥러닝(여러 층)과 달리, 간단하지만 효과적인 문제 해결 가능

### 2. 퍼셉트론의 작동 원리

#### Step 1: 이미지를 숫자로 변환
```python
이미지(64×64 픽셀, 그레이스케일)
→ 4,096개의 숫자로 변환
→ 각 숫자는 0~1 사이의 밝기 값
```

**예시:**
```
원본 이미지: 😊 (64×64 픽셀)
↓
숫자 배열: [0.2, 0.5, 0.8, 0.1, 0.9, ... ] (4,096개)
```

#### Step 2: 가중치 곱셈
각 픽셀 값에 **가중치(weight)** 를 곱합니다.

```
가중치란? 
→ 각 픽셀이 "네컷인지 판단하는데 얼마나 중요한지"를 나타내는 값

예시:
- 격자 경계선 부분: 가중치 높음 (중요!)
- 배경 부분: 가중치 낮음 (덜 중요)
```

**계산 과정:**
```
입력1 × 가중치1 + 입력2 × 가중치2 + ... + 입력4096 × 가중치4096
= 총합(z)
```

#### Step 3: 편향(bias) 더하기
```
z = (입력들의 가중 합) + 편향

편향이란?
→ 판단 기준을 조정하는 값
→ "얼마나 쉽게 네컷이라고 판단할지" 결정
```

#### Step 4: 시그모이드 함수 적용
```python
시그모이드(z) = 1 / (1 + e^(-z))

결과: 0~1 사이의 확률값
- 0.9 → 90% 확률로 네컷
- 0.1 → 10% 확률로 네컷 (= 90% 일반)
```

**시그모이드 함수의 역할:**
```
입력(z): -∞ ~ +∞ (아무 숫자나 가능)
↓
출력: 0 ~ 1 (항상 확률값으로 변환)

예시:
z = 5 → 시그모이드(5) = 0.993 → 99.3% 네컷
z = -3 → 시그모이드(-3) = 0.047 → 4.7% 네컷
```

#### Step 5: 최종 판단
```
확률 ≥ 0.5 → 네컷!
확률 < 0.5 → 일반 사진
```

### 3. 학습 과정 (어떻게 똑똑해지나?)

#### 🎓 학습의 핵심: 오차 수정

```
1. 예측하기
   모델: "이 사진은 90% 확률로 네컷이에요!"
   
2. 정답과 비교
   정답: "아니요, 이건 일반 사진입니다."
   오차: 0.9 - 0 = 0.9 (큰 오류!)

3. 가중치 조정
   "아, 이런 특징은 네컷이 아니구나!"
   → 해당 가중치를 낮춤
   
4. 반복
   수천 번 반복하면서 점점 정확해짐
```

#### 📊 손실 함수(MSE - Mean Squared Error)
```python
손실 = (예측값 - 정답)²의 평균

목표: 손실을 최소화!

예시:
에포크 1: 손실 = 0.25 (25% 오류)
에포크 10: 손실 = 0.10 (10% 오류)
에포크 100: 손실 = 0.03 (3% 오류) ✅
```

#### 🎯 경사 하강법(Gradient Descent)
```
언덕을 내려가듯이 손실을 줄이는 방법:

1. 현재 위치에서 어느 방향으로 가야 손실이 줄어들지 계산
2. 그 방향으로 조금씩 이동 (학습률만큼)
3. 반복하면 최저점 도달!

학습률(Learning Rate):
- 크면: 빠르지만 불안정
- 작으면: 느리지만 안정적
- 적절한 값: 0.01 (이 프로젝트에서 사용)
```

**문제 상황:**
- 실제 네컷 사진 데이터셋이 공개되어 있지 않음
- 학습에 필요한 대량의 네컷 이미지 확보 어려움

**해결책: 자동 네컷 사진 생성기 구현**

네컷 사진 생성기(`generate_fourcut.py`)를 직접 개발하여 학습 데이터를 생성했습니다:

```python
# 생성기 작동 원리
1. 투명한 네컷 프레임(템플릿) 준비
   - 4개의 격자 슬롯이 있는 PNG 프레임
```

```
일반 사진 4장      →    격자 배열    →    프레임 합성    →    네컷 완성!
🌄🍕🐶🌊           □□              🖼️              🎨
```

- ✅ **안전성**: 테스트 데이터 누출 방지

### 3단계: 이미지 전처리 🎨

**왜 전처리가 필요한가?**
- 원본 이미지: 크기가 제각각 (1920×1080, 640×480 등)
- AI 입력: 고정된 크기 필요

**전처리 과정:**
```python
1. 크기 조정: 128×128 픽셀로 통일
2. 흑백 변환: 컬러(3채널) → 그레이스케일(1채널)
   - 이유: 색상보다 "패턴(격자)"이 중요
3. 정규화: 0~255 범위 → 0~1 범위
   - 이유: 계산 안정성
4. 평탄화: 2차원(128×128) → 1차원(16,384)
   - 이유: 퍼셉트론 입력 형태
```

**시각화:**
```
원본 이미지          전처리 후
[1920×1080]    →    [128×128]
RGB 컬러       →    그레이스케일
픽셀값 0~255   →    0~1
2D 배열        →    1D 배열(16,384개)
```

### 4단계: 모델 학습 🎓

**학습 설정:**
```python
학습률: 0.001
에포크: 최대 2000회 (조기 종료 적용)
이미지 크기: 128×128 (16,384 차원)
데이터 밸런싱: 언더샘플링 (1:1 비율)
정규화: L2 (λ=0.001)
```

**한 에포크의 과정:**
```
1. 순전파(Forward Pass)
   입력 → 가중치 곱셈 → 시그모이드 → 예측

2. 손실 계산
   (예측 - 정답)² 계산

3. 역전파(Backward Pass)
   기울기 계산 (어느 방향으로 조정할지)

4. 가중치 업데이트
   가중치 = 가중치 - (학습률 × 기울기)
```

**학습 진행 예시:**
```
Epoch 1/100 - Loss: 0.1943
Epoch 10/100 - Loss: 0.0365
Epoch 50/100 - Loss: 0.0323
Epoch 100/100 - Loss: 0.0318  ✅
```

```
                예측: 일반    예측: 네컷

```

**성능 지표:**

- 네컷 정확도: 88%

## 🚀 고급 과적합 방지 기법

이 프로젝트는 단층 퍼셉트론의 일반화 성능을 높이기 위해 다음 고급 기법들을 구현했습니다:

### 1. **Validation Set (검증 세트)** ✅

**개념:**
- 데이터를 **학습(Train) / 검증(Validation) / 테스트(Test)** 3개로 분할
- 학습 중에는 검증 세트로 성능을 모니터링하고, 최종 평가는 테스트 세트로 수행

**왜 필요한가?**
```
기존 방식 (2분할):
Train (80%) → 학습에 사용
Test (20%)  → 최종 평가에만 사용
문제: 학습 중 과적합 여부를 알 수 없음!

개선 방식 (3분할):
Train (65%)      → 학습에 사용
Validation (15%) → 학습 중 성능 모니터링
Test (20%)       → 최종 평가 (한 번도 본 적 없는 데이터!)
```

**작동 원리:**
```python
# 데이터 분할
X_train (65%)  → 가중치 업데이트에 사용
X_val (15%)    → 매 에포크마다 손실 체크 (학습에는 미사용)
X_test (20%)   → 학습 완료 후 최종 평가만 수행

# 에포크마다 실행
1. 학습 데이터로 가중치 업데이트
2. 검증 데이터로 손실 계산 (업데이트 없음)
3. 검증 손실이 나빠지면 경고!
```

### 2. **Early Stopping (조기 종료)** ⏹️

**개념:**
- 검증 손실이 일정 에포크 동안 개선되지 않으면 학습을 자동 중단
- 과적합이 시작되기 전에 학습을 멈춤

**왜 필요한가?**
```
일반적인 학습 과정:
Epoch 1-50:   학습↑ 검증↑ (좋은 학습!)
Epoch 51-100: 학습↑ 검증→ (정체)
Epoch 101-200: 학습↑ 검증↓ (과적합 시작!)
               ↑
         이 시점에서 멈춰야 함!
```

**작동 원리:**
```python
patience = 50  # 50 에포크 동안 개선 없으면 중단
min_delta = 0.0001  # 최소 개선폭

best_val_loss = 무한대
patience_counter = 0

for epoch in range(epochs):
    현재_val_loss = 검증_손실_계산()
    
    if 현재_val_loss < best_val_loss - min_delta:
        # 개선됨!
        best_val_loss = 현재_val_loss
        patience_counter = 0
        모델_저장()  # 최적 가중치 저장
    else:
        # 개선 안됨
        patience_counter += 1
    
    if patience_counter >= patience:
        print("조기 종료!")
        최적_모델_복원()
        break
```

**실제 예시:**
```
Epoch 100: Val Loss 개선! 0.0325 (정확도: 0.8200)
Epoch 110: Val Loss 개선! 0.0318 (정확도: 0.8400)
Epoch 120: Val Loss 개선! 0.0312 (정확도: 0.8500)
Epoch 130: 개선 없음 (1/50)
Epoch 140: 개선 없음 (2/50)
...
Epoch 170: 개선 없음 (50/50)

⏹️ Early Stopping at Epoch 170
   최적 에포크: 120
   최적 검증 손실: 0.0312
   최적 검증 정확도: 0.8500
🏆 최적 모델 사용 (Epoch 120으로 복원)
```

### 3. **L2 정규화 (Ridge Regularization)** 🔧

**개념:**
- 손실 함수에 가중치의 제곱합을 패널티로 추가
- 가중치가 너무 커지는 것을 방지

**수식:**
```
일반 손실: Loss = MSE(예측, 정답)
L2 추가: Loss = MSE(예측, 정답) + λ × Σ(가중치²)
                                    ↑
                              L2 패널티 항
```

**효과:**
```
L2 없음:
→ 특정 픽셀에 과도하게 의존
→ 가중치: [0.1, 5.2, -4.8, 0.2, 7.1, ...]
→ 학습 데이터에만 특화 (과적합!)

L2 있음 (λ=0.01):
→ 가중치 골고루 분산
→ 가중치: [0.3, 0.8, -0.5, 0.4, 0.9, ...]
→ 일반화 성능 향상!
```

## 🎯 핵심 알고리즘 상세 설명

### 1. 순전파(Forward Propagation)

```python
# 수학적 표현
z = W · X + b
y = σ(z) = 1 / (1 + e^(-z))

# 코드
def predict_proba(self, X):
    z = np.dot(X, self.weights) + self.bias
    return self.sigmoid(z)
```

**실제 계산 예시:**
```
입력 X: [0.2, 0.5, 0.8, ..., 0.3] (4,096개)
가중치 W: [0.1, -0.2, 0.5, ..., 0.7] (4,096개)

z = 0.2×0.1 + 0.5×(-0.2) + ... + 0.3×0.7 + bias
z = 2.5

y = 1 / (1 + e^(-2.5)) = 0.924
→ 92.4% 확률로 네컷!
```

### 2. 손실 함수(Loss Function)

```python
# MSE (Mean Squared Error)
Loss = (1/N) × Σ(y_pred - y_true)²

# 코드
def compute_loss(self, y_true, y_pred):
    return np.mean((y_pred - y_true) ** 2)
```

**손실이 낮을수록 좋은 이유:**
```
손실 = 0.5 → 예측이 정답과 많이 다름 ❌
손실 = 0.05 → 예측이 정답과 비슷함 ✅
손실 = 0.001 → 예측이 정답과 거의 같음 ✨
```

### 3. 경사 하강법(Gradient Descent)

```python
# 기울기 계산
error = (y_pred - y_true) × y_pred × (1 - y_pred)
dW = (1/N) × X^T · error
db = mean(error)

# 가중치 업데이트
W = W - learning_rate × dW
b = b - learning_rate × db
```

**직관적 이해:**
```
기울기가 양수 → 가중치를 줄여야 손실 감소
기울기가 음수 → 가중치를 늘려야 손실 감소

학습률 = 0.01 → 천천히 조정 (안정적)
학습률 = 0.1 → 빠르게 조정 (불안정할 수 있음)
```

   - 비선형 특징 추출 불가

2. **정확도 한계**
   - 약 92% 정확도 (완벽하지 않음)
   - 향상을 위해서는 더 복잡한 모델 필요

3. **데이터 손실**
   - 언더샘플링으로 일반 사진 1,656개 미사용
   - 오버샘플링이나 다른 방법 고려 가능

---

### 향후 개선 방안

1. **모델 복잡도 증가**
   - 다층 퍼셉트론(MLP) 사용
   - 은닉층 2~3개 추가
   - 예상 정확도: 95~98%

2. **데이터 증강**
   - 회전, 좌우 반전, 밝기 조절
   - 학습 데이터 양 2~3배 증가 효과

3. **앙상블 기법**
   - 여러 모델의 예측 결합
   - 정확도 2~3% 추가 향상 가능

4. **CNN 적용**
   - 격자 패턴 자동 감지
   - 예상 정확도: 98~99%

## 🔍 왜 단층 퍼셉트론으로도 충분한가?

### 문제의 특성
```
네컷 사진의 특징:
✓ 명확한 격자 패턴 (2×2, 4개 구역)
✓ 경계선이 뚜렷함
✓ 규칙적인 구조

→ 선형 분리 가능한 문제!
```

### 선형 분리란?
```
       일반 사진들     |     네컷 사진들
          ●●●          |        ■■■
           ●           |         ■
          ●●           |        ■■
    ────────────────────────────────
         (이 선으로 구분 가능!)
```

단층 퍼셉트론은 **선 하나로 구분할 수 있는 문제**에 최적화되어 있습니다.

### 딥러닝이 필요한 경우
```
❌ 현재 문제: 네컷 vs 일반 → 단층 퍼셉트론 충분
✅ 복잡한 문제:
   - 개/고양이/새/물고기 구분 → CNN 필요
   - 여러 종류 네컷 동시 구분 → 다층 신경망 필요
```
