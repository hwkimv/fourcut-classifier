# 데이터 디렉토리

이 디렉토리는 네컷사진 판별 모델의 데이터를 저장하는 공간입니다.

## 디렉토리 구조

```
data/
├── raw/              # 원본 이미지 데이터
│   ├── fourcut/      # 네컷사진 이미지
│   └── non_fourcut/  # 일반 사진 이미지
└── processed/        # 전처리된 데이터 및 모델 가중치
    └── model_weights.npz  # 학습된 모델 가중치
```

## 사용 방법

1. **데이터 준비**
   - `data/raw/fourcut/` 폴더에 네컷사진 이미지를 추가합니다.
   - `data/raw/non_fourcut/` 폴더에 일반 사진 이미지를 추가합니다.
   - 지원 형식: `.jpg`, `.jpeg`, `.png`

2. **모델 학습**
   - 데이터가 준비되면 `src/train.py`를 실행하여 모델을 학습합니다.
   - 학습된 모델 가중치는 `data/processed/model_weights.npz`에 저장됩니다.

3. **모델 평가**
   - `src/evaluate.py`를 사용하여 저장된 모델로 새로운 이미지를 판별할 수 있습니다.

## 주의사항

- 충분한 양의 학습 데이터를 준비해야 좋은 성능을 얻을 수 있습니다.
- 네컷사진과 일반 사진의 비율을 비슷하게 맞추는 것이 좋습니다.
- 다양한 조명, 각도, 배경의 이미지를 포함하면 모델의 일반화 성능이 향상됩니다.
